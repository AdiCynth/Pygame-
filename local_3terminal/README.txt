HOW TO RUN (all on one PC, 3 terminals):

  Terminal 1:  python server.py
  Terminal 2:  python client.py       (Player 1 - left paddle)
  Terminal 3:  python client.py       (Player 2 - right paddle)

CONTROLS (each window only responds to its own keys):
  Player 1 window:  W = up,  S = down
  Player 2 window:  Up Arrow = up,  Down Arrow = down

  Both windows:  SPACE = start,  R = restart,  ESC = quit

TIPS:
- Drag/resize the windows and place them side by side on one monitor
- The game scales to fit any window size (aspect ratio preserved)
- Click on a window to give it keyboard focus before pressing keys
